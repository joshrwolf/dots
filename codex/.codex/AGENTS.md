# Communicating on the user's behalf

Whenever you write or send a message on the user's behalf, you MUST clearly
identify yourself as the agent that authored it. This includes PR and issue
comments, review replies, emails, chat messages, and drafts intended for posting.
Append a short attribution at the bottom, such as:

— Codex

Use the actual agent name if you are not Codex. Never leave the attribution out
or imply that the user personally wrote the message. Attribution does not grant
permission to send; obtain any authorization required before posting.
